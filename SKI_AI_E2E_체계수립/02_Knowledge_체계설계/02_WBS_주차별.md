## 선후행 의존 관계 (Critical Path)

```
P0 범위합의(W1)
   └→ P1 질의 수집(W2~W3)  ★ 이후 모든 Phase의 근거
        ├→ P2 표준 모델(W3~W5)
        │     ├→ P3 구조화 방안(W5~W9) ──┐
        │     └→ P4 Hub 요건(W10~W11) ←──┤
        └→ P3B 데이터 요건(W7~W8) ────────┘
                                          └→ P5 통합(W13~W14)
```

**임계 경로**: `P1 질의 수집 → P2 표준 모델 → P3 구조화 방안 → P4 Hub 요건 → P5`
- P1이 1주 지연되면 전 과업이 1주 밀립니다. 인터뷰 일정은 **착수 전에** 확보해야 합니다.
- P3B(LLM 데이터)는 임계 경로 밖이므로, 일정 압박 시 3B-1(외부 사례 조사) 범위를 먼저 줄입니다.

## 투입 가정

기획서 10페이지 인력계획 기준으로 본 과업(②)은 3.5개월 간 지속 투입이 필요하며,
W2~W3(인터뷰)과 W5(시범 태깅), W9(파일럿 전환)에 현업 참여 부하가 집중됩니다.
해당 3개 구간의 현업 시간은 착수 시점에 미리 예약해 두십시오.
