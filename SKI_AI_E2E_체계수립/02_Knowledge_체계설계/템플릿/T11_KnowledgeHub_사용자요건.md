# T11. Enterprise Knowledge Hub 사용자 요건 정의서

## 1. 페르소나 정의

| ID | 페르소나 | 대표 역할 | 주 이용 목적 | 이용 빈도 | 기술 숙련도 | 근거 인터뷰 |
|---|---|---|---|---|---|---|
| P1 | 현장 운전원 | 교대 근무자 | 이상 대응 시 과거 사례 조회 | 일 | 낮음 (모바일 중심) | |
| P2 | 정비 담당 | | 설비 이력·절차 확인 | 일~주 | 중 | |
| P3 | 기술·연구 | | 기술 자료 탐색, 보고서 작성 | 주 | 높음 | |
| P4 | 지식 관리자 | 조직별 지정 | 소관 지식 품질 점검·갱신 | 주 | 중 | |
| P5 | 시스템/AI Agent | 비인격 | 지식 조회·인용 (API) | 상시 | — | |

> **P5(AI Agent)를 반드시 페르소나로 포함하십시오.** 본 과업의 목적이 AI 활용이므로, Hub의 1차 소비자는 사람이 아니라 Agent입니다. 사람 중심으로만 요건을 뽑으면 API·인용 추적 요건이 통째로 누락됩니다.
