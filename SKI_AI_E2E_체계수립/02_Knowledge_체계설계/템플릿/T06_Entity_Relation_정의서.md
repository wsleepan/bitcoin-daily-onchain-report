# T06. 경량 Entity–Relation 정의서

**사용 시점** Phase 2 / Activity 2-5 (W4~W5)
**산출물 귀속** CLX Ontology 표준 모델
**범위** Entity 10~15종 / Relation 10종 내외 — **형식 온톨로지(OWL) 구현은 범위 외**

> **설계 방법: 질의에서 역산한다.** Entity를 먼저 나열하지 마십시오. Phase 1에서 수집한 실제 질의문을 하나씩 놓고 "이 질문에 답하려면 무엇과 무엇이 연결되어 있어야 하는가"를 묻습니다. 어떤 질의에도 쓰이지 않는 Entity·Relation은 넣지 않습니다.

## 1. 질의 → 관계 역산 워크시트

| 질의 원문 (T02 수집) | 필요한 연결 | 도출 Entity | 도출 Relation |

| "3호기 압축기 작년 여름 트립 원인이 뭐였지?" | 설비 ↔ 이상현상 ↔ 시점 ↔ 원인분석 문서 | 설비, 이상현상, 지식문서 | 설비-[발생]-이상현상, 지식문서-[분석대상]-이상현상 |

## 4. 모델 다이어그램 (텍스트 표기)

```
   [조직] ←소속─ [인원] ─작성→ [지식문서] ─대상으로_함→ [설비] ─구성←─ [공정]
                                  │  ↑                      │
                            개정/참조│  │근거                  │발생
                                  ↓  │                      ↓
                              [지식문서]  └───────────── [이상현상] ←대응─ [조치]
                                  ↑
                                산출│
                               [과제]
```
