# T08. 신규 지식 데이터 축적 및 갱신 가이드

**사용 시점** Phase 3 / Activity 3-3, 3-4 (W7~W9)
**산출물 귀속** 신규 지식 데이터 축적 및 갱신 가이드

> **원칙: 별도 등록 절차를 만들지 않는다.** "문서를 만든 뒤 지식 시스템에 등록하세요"는 지켜지지 않습니다. 지식은 **업무 문서를 작성하는 그 행위 안에서** 축적되어야 하며, 메타는 양식에 내재된 선택 항목으로 자연히 입력되어야 합니다.

## 1. 지식 생애주기와 단계별 규칙

| 단계 | 트리거 | 수행 주체 | 필수 행위 | 자동화 | 산출 상태(T03-F4) |
|---|---|---|---|---|---|
| 생성 | 업무 수행 | 작성자 | 표준 양식으로 작성 (메타 자동/선택 입력) | 메타 M01~M06, M10~M13 자동 | 작성중 |
| 검토 | 작성 완료 | 검토자 | 내용 정확성 확인 | 워크플로 알림 | 검토중 |
| 승인 | 검토 완료 | 승인자 | 공개 범위·보안등급 확정 | 상태 자동 전이 | 승인됨 |
| 공개 | 승인 | 시스템 | 색인 생성, 청킹, 임베딩 | 전자동 | 활용중 |
| 갱신 | 유효기간 도래 / 변경 사유 발생 | 소관 조직 | 유효성 판정 → 개정 또는 유효기간 연장 | 만료 예고 알림 | 활용중 / 작성중 |
| 보존 | 활용도 저하 | 시스템 | 검색 우선순위 하향, 원본 보존 | 규칙 기반 자동 | 보존 |
| 폐기 | 보존기간 만료 / 무효화 | 소관 조직 | 폐기 승인, 메타는 보존 | 승인 후 자동 | 폐기 |

> **폐기 시 본문은 제거해도 메타와 식별자는 남깁니다.** 과거 문서를 인용한 다른 문서의 링크가 끊기지 않아야 하고, AI가 "그 문서는 폐기되었습니다"라고 답할 수 있어야 합니다.

## 2. 메타데이터 입력 방식 설계 (원칙 4 적용)

| 메타 요소 | 입력 방식 | 사용자 부담 | 설계 |
|---|---|---|---|
| M01~M06, M10~M13 | 시스템 자동 | 없음 | 로그인·워크플로·채번 연계 |
| M07 업무기능 | 양식 내 드롭다운 | 클릭 1회 | 작성자 조직 기반 기본값 제시 |
| M08 설비·공정 | 양식 내 검색 선택 | 클릭 1~2회 | 최근 사용 이력 상위 노출 + 본문 NER 추천 |
| M09 보안등급 | 기본값 + 확인 | 확인만 | 문서유형별 기본값 사전 설정 |
| M15 요약 | LLM 자동 생성 후 확인 | 확인만 | |

**사용자 추가 입력 시간 목표: 문서 1건당 30초 이내**

## 4. 품질 기준 및 측정 (Activity 3-4)

| 지표 | 정의 | 측정식 | 목표 | 측정 주기 | 미달 시 조치 |
|---|---|---|---|---|---|
| 완전성 | 필수 메타 충족률 | 필수메타 완비 건수 / 전체 건수 | ≥95% | 월 | 결측 목록을 소관 조직에 통보 |
| 정확성 | 메타 값의 정오 | 표본 100건 검수 정답률 | ≥90% | 분기 | 자동추출 규칙 보정 |
| 최신성 | 유효기간 내 비율 | 유효 건수 / 유효기간 관리 대상 | ≥90% | 월 | 만료 임박 알림 강화 |
| 일관성 | 동일 대상의 표기 통일 | 통제어휘 매칭률 | ≥95% | 분기 | T05 어휘 사전 보완 |
| 활용도 | 조회·인용 발생 | 최근 6개월 조회 ≥1회 비율 | ≥50% | 반기 | 저활용 유형 재검토 |

## 5. 역할과 책임 (R&R)

| 역할 | 담당 | 책임 |
|---|---|---|
| 지식 작성자 | 업무 수행자 | 표준 양식 준수, 메타 선택 항목 입력 |
| 지식 검토·승인자 | 조직 책임자 | 내용 정확성, 보안등급 판정 |
| 지식 관리자 (조직별) | 각 조직 지정 1인 | 소관 지식 유효성 점검, 갱신·폐기 판정 |
| 어휘 관리자 | 지식 총괄 조직 | T05 통제어휘 등록·변경 승인 |
| 표준 관리자 | 지식 총괄 조직 | T03·T04 분류·메타 표준 변경 관리 |
| 품질 모니터 | 지식 총괄 조직 | 지표 측정·리포팅, 미달 조치 요청 |

> **조직별 지식 관리자 지정이 이 가이드의 성패를 가릅니다.** 총괄 조직 혼자서는 유효성 판정을 할 수 없습니다. 착수 시점에 지정 가능 여부를 확인하고, 불가하면 갱신 규칙을 자동 규칙 중심으로 재설계하십시오.
