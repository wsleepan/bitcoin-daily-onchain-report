# T02. 활용 실태 인터뷰 가이드

**사용 시점** Phase 1 / Activity 1-2, 1-3 (W2~W3)
**대상** 지식 생산자 / 활용자 / 시스템 운영자 각 3~5명
**소요** 1인 60~90분, 2인 1조(진행 1, 기록 1)

> **이 인터뷰의 진짜 목적은 Q3입니다.** 실제 질의문 원문 수집이 이후 모든 Phase(표준 모델 범위, 구조화 단위, LLM 데이터 요건)의 근거가 됩니다. 시간이 부족하면 Q3에 시간을 몰아주십시오.

## 사전 안내 (5분)
- 목적: 현행 평가가 아니라 향후 AI 활용을 위한 지식 체계 설계
- 익명 처리, 개인 평가와 무관함을 명확히 고지

## Q1. 생산 (15분)
1. 어떤 문서를 정기/비정기로 작성하십니까? 각각 얼마나 자주?
2. 작성 시 정해진 양식이 있습니까? 실제로 얼마나 지켜집니까?
3. 작성한 문서는 어디에 저장합니까? 개인 PC/공유폴더/시스템 비중은?
4. 작성 시 가장 번거로운 부분은 무엇입니까?
5. (양식이 있다면) 양식의 어떤 항목이 실제로는 잘 안 채워집니까? 왜?

## Q2. 검색·활용 (15분)
1. 필요한 자료를 주로 어떻게 찾습니까? (시스템 검색 / 사람에게 물어봄 / 개인 보관본)
2. 검색이 실패하는 경우는 주로 어떤 상황입니까?
3. 사람에게 물어보는 경우, 왜 시스템에서 못 찾습니까?
4. 같은 내용의 문서가 여러 버전으로 존재하는 문제가 있습니까? 어느 것이 최신인지 어떻게 압니까?

## Q3. ★ 실제 질의 수집 (30분) — 핵심
> 추상적으로 묻지 말고 **구체적 사건**을 끌어내십시오. 원문 표현 그대로 받아 적습니다.

1. **최근 1개월 내에 자료를 찾아본 일**을 떠올려 주십시오. 무엇을 찾으려 했습니까?
   - 그때 머릿속의 질문을 **말한 그대로** 알려주십시오. (예: "3호기 압축기 작년 여름 트립 원인이 뭐였지?")
2. 그 자료를 찾았습니까? 얼마나 걸렸습니까?
3. **찾다가 포기한 경험**이 있습니까? 무엇을 찾으려 했습니까?
4. 신입/전배자가 자주 묻는 질문은 무엇입니까?
5. "이런 걸 물어보면 바로 답해주는 게 있으면 좋겠다" 하는 것은?

**기록표** — 1인당 3~5건, 전체 30~50건 목표

|---|---|---|---|---|---|---|
| | | | | 찾음/실패/사람에게 물음 | | |

`질의 유형` — 사실조회 / 이력추적 / 원인분석 / 절차안내 / 판단지원 (인터뷰 후 분류)

## Q4. 갱신·관리 (10분)
1. 작성한 문서를 나중에 갱신합니까? 어떤 계기로?
2. 오래되어 더 이상 유효하지 않은 문서는 어떻게 처리됩니까?
3. 문서의 정확성은 누가 검증합니까?

## Q5. 마무리 (5분)
1. 지식 관리에서 가장 시급히 개선되어야 할 한 가지는?
2. 추가로 만나볼 만한 분을 추천해 주시겠습니까?
