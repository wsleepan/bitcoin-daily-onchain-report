# T05. 통제어휘 · 용어사전

**사용 시점** Phase 2 / Activity 2-4 (W4~W5)
**산출물 귀속** CLX Ontology 표준 모델
**표현 방식** SKOS 개념 참조 (대표어 / 동의어 / 상위어 / 하위어 / 관련어)

> 검색 실패의 최대 원인은 분류 부재가 아니라 **같은 것을 다르게 부르는 것**입니다. AI Agent 환경에서는 이 문제가 그대로 답변 누락으로 이어집니다.

## 2. 수집 절차

1. **자동 수집** — 대표 문서유형 각 100건에서 명사구 빈도 추출, 상위 200개 후보화
2. **인터뷰 수집** — T02 진행 중 언급된 현장 용어를 즉시 기록 (구어체 약어가 여기서만 나옵니다)
3. **마스터 대조** — 설비·제품·조직 마스터의 공식 명칭과 매핑
4. **SME 검증** — 공정별 SME가 대표어 확정 및 동의어 보완

## 3. 대표어 선정 규칙

| 우선순위 | 규칙 |
|---|---|
| 1 | 사내 마스터의 공식 명칭이 있으면 그것을 대표어로 함 |
| 2 | 마스터가 없으면 문서상 출현 빈도가 가장 높은 표기 |
| 3 | 약어는 원칙적으로 동의어로 두되, 현장에서 원어를 쓰지 않는 경우(예: PLC)는 약어를 대표어로 함 |
| 4 | 한/영 혼용 시 문서 작성 언어 기준 (한국어 문서 → 한국어 대표어, 영문 병기) |

## 4. 우선 구축 범위

전 어휘를 다루지 말고 아래 4개 영역만 우선 구축합니다 (각 50~100개 목표).

| 영역 | 대상 | 담당 SME | 목표 개수 | 진행률 |
|---|---|---|---|---|
| 설비 명칭 | 회전기기·정지기기·계장 | 정비 | | |
| 공정 단위 | 공정·유닛·배치 | 운전 | | |
| 이상현상 | 트립·누출·품질이상 등 | 운전/품질 | | |
| 제품·원료 | 제품군·규격 | 생산관리 | | |

## 5. 유지관리

| 항목 | 규칙 |
|---|---|
| 신규 어휘 등록 | 요청 → 소관 SME 검토 → 어휘 관리자 승인 → 월 1회 반영 |
| 대표어 변경 | 영향 문서 조회 후 승인, 구 대표어는 동의어로 유지 (**삭제 금지**) |
| 마스터 동기화 | 분기 1회 설비·조직 마스터와 대조 |
| 폐기 | 사용 중단 어휘도 삭제하지 않고 `폐기` 상태로 보존 (과거 문서 검색 유지) |
