# T09. 도메인 LLM 필요 데이터 유형 및 요건 정의서

**사용 시점** Phase 3B / Activity 3B-2 (W7~W8)
**산출물 귀속** 필요 데이터 유형 및 요건

> **모든 데이터 요건은 Phase 1의 실제 질의로 역추적되어야 합니다.** 근거 질의가 없는 요건은 "있으면 좋을 것 같아서"이며, 우선순위 판단을 왜곡합니다.

| 시나리오 ID | 시나리오 | 근거 질의 (T02) | 답변에 필요한 지식 | 필요 데이터 유형 | 활용 방식 |

`활용 방식` — RAG(검색증강) / 파인튜닝 / 사전학습 추가 / 프롬프트 예시

> **활용 방식 판정이 요건을 완전히 바꿉니다.** RAG는 최신성·출처 추적이 핵심이고 소량으로도 동작하지만, 파인튜닝은 규모·품질·라벨이 핵심입니다. 대부분의 시나리오는 RAG로 충분하며, 파인튜닝은 도메인 언어 이해가 근본적으로 부족할 때만 검토합니다.
