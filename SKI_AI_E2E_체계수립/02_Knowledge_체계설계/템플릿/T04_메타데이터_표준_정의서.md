# T04. 메타데이터 표준 정의서

**사용 시점** Phase 2 / Activity 2-3 (W4~W5)
**산출물 귀속** CLX Ontology 표준 모델 (본 과업의 **중핵 산출물**)

> **설계 철칙** — `자동추출` 컬럼이 이 표의 성패를 가릅니다. 사람이 손으로 채워야 하는 필수 메타가 많을수록 체계는 반드시 사문화됩니다. 목표: **필수 메타 중 자동추출·양식내재 60% 이상**.

## 1. 공통 필수 메타데이터 (전 문서유형 공통, 12~15개 목표)

| M13 | 원본 위치 | 출처 시스템·경로 | 필수 | 1 | URI | — | ○ | 수집 시 자동 | DC:source | |
| M14 | 관련 지식 | 연관 문서 ID | 선택 | 0..n | 식별자 | — | △ | 인용/링크 파싱 | DC:relation | |
| M15 | 요약 | 내용 요약 | 선택 | 1 | 텍스트(500자) | — | ○ | LLM 자동 생성 | DC:description | |

`자동추출` 범례 — `○` 완전 자동 / `△` 양식 내재화 또는 반자동(추천 후 확인) / `×` 수기 입력

**자동화율 집계**
| 구분 | 건수 | 비율 |
|---|---|---|
| 필수 메타 총계 | | |
| 자동(○) | | |
| 양식내재·반자동(△) | | |
| 수기(×) | | |
| **○+△ 비율 (목표 ≥60%)** | | **%** |

> `×`(수기)로 남은 필수 항목이 있다면, ① 양식에 내재화하거나 ② 선택으로 강등하거나 ③ 삭제하십시오. 그대로 두는 선택지는 없습니다.

## 3. 요소별 상세 정의 (개별 카드 — 요소마다 1장)

```
요소 ID     : M08
요소명       : 설비·공정
정의         : 본 지식이 대상으로 하는 설비 또는 공정 단위
필수 여부    : 조건부 필수 (설비 관련 문서유형에 한함)
카디널리티   : 0..n
값 도메인    : T03-F2 설비·공정 분류 코드 (설비 마스터 참조)
통제어휘     : T05 설비 명칭 사전 적용
자동추출     : △ — 작성 양식의 선택 항목으로 내재화 + 본문 개체명 인식 보조
검증 규칙    : 설비 마스터에 존재하는 코드여야 함
결측 시 처리 : "미지정"으로 저장하고 월간 품질 리포트에 계상
변경 관리    : 설비 마스터 변경 시 분기 단위 동기화
```
