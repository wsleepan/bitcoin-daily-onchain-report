# 유튜브 쇼츠 생성기

`reports/YYYY-MM-DD.md` 리포트를 읽어 **1080x1920 / 약 54초 / 무음** 쇼츠 MP4와
업로드용 제목·설명·태그 텍스트를 만듭니다.

## 준비물

```bash
pip install pillow imageio-ffmpeg          # 렌더링 + ffmpeg 바이너리
apt-get install -y fonts-nanum             # 한글 폰트 (나눔스퀘어/나눔고딕)
```

## 사용법

```bash
python3 video/make_short.py                      # reports/ 의 가장 최근 리포트
python3 video/make_short.py reports/2026-07-02.md
python3 video/make_short.py --out out/btc.mp4
python3 video/make_short.py --force              # 값이 비어 있어도 강행
```

결과물은 기본적으로 `video/out/` 에 저장됩니다 (git에 커밋되지 않음).

- `shorts-<날짜>.mp4` — 영상
- `shorts-<날짜>.txt` — 유튜브 제목 / 설명 / 태그

데이터 수집에 실패한 날짜의 리포트는 어떤 값이 비었는지 알려주고 생성을 중단합니다.

## 파일

- `make_short.py` — CLI. 타임라인 정의, 프레임을 ffmpeg에 파이프로 넘겨 인코딩
- `scenes.py` — 씬별 렌더링. 씬 추가·순서 변경은 `make_short.py`의 `TIMELINE`에서
- `render_kit.py` — 팔레트·폰트·이징·그리기 헬퍼 (1080x1920 좌표계, 안전 여백)
- `report_parser.py` — 리포트 마크다운 → 값 추출, 수집 실패 감지
- `metadata.py` — 유튜브 제목·설명·태그 생성

## 색

dataviz 레퍼런스 팔레트의 다크 스텝을 씁니다. 배경 `#0d0d0d` 기준으로
명도대·채도·색각이상 분리도·대비 검사를 모두 통과한 값이며, 색이 의미를 단독으로
지지 않도록 모든 지표에 숫자·부호·아이콘 라벨을 함께 붙입니다.

- 양(+)/음(-) 변화: 파랑 `#3987e5` ↔ 빨강 `#e66767` (다이버징)
- 공포탐욕지수: 공포(빨강) ↔ 탐욕(파랑), 50 중립 회색
- 신호 배지: 매수 `#0ca30c` ▲ / 중립 회색 ■ / 매도 `#d03b3b` ▼
