## 선후행 의존 관계 (Critical Path)

```
P0 범위·MCP 합의 (W1)
  └→ P1 Agent 유형 · Action Pattern (W2~W3)   ★ 이후 전 Phase의 근거
       ├→ P2 Readiness 진단 · Gap (W3~W6)
       │     ├→ P3 데이터·메타 요건 (W4~W9) ──────┐
       │     └→ P4 연계 구조·적용 기준 (W6~W11) ★ ├→ P7 목표구조·로드맵 (W10~W13)
       │            └→ P5 권한 모델 (W7~W12) ─────┤        └→ P8 실행과제 (W12~W14)
       └→ P6 Lineage·변경관리 (W9~W13) ───────────┘
```

**임계 경로**: `P0 → P1 Action Pattern → P2 Gap → P4 연계 설계 → P7 목표구조 → P8`

- **P1이 임계 경로의 시작점입니다.** Action Pattern이 안 나오면 P4의 적합성 평가(4-3)를 할 수 없고, 그러면 MCP 판단도 못 합니다. W3 마일스톤을 반드시 지키십시오.
- **P4와 P5는 상호 의존적입니다.** 연계 아키텍처가 권한 모델을 제약하고, 권한 모델이 아키텍처를 제약합니다. W9~W11에 두 Phase를 **함께 리뷰**하도록 배치했습니다.
- P6(Lineage)은 임계 경로 밖입니다. 일정 압박 시 6-3(변경 시나리오 분석) 범위를 먼저 줄입니다.
