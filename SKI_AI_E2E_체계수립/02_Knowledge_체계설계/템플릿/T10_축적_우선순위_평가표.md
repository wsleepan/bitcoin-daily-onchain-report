# T10. 학습 데이터 축적 우선순위 및 개발 로드맵

**사용 시점** Phase 3B / Activity 3B-4 (W11~W12)
**산출물 귀속** 학습 데이터 축적 우선순위 및 개발 로드맵

## 1. 평가 축 정의

| 대분류 | 세부 축 | 배점 | 판정 기준 |
|---|---|---|---|
| **가치** | 활용도 (근거 시나리오 수 × 시나리오 발생 빈도) | 1~5 | 5 = 일 단위 발생 핵심 시나리오의 주 근거 |
| | 효과 (시간 절감·품질·안전 기여) | 1~5 | 5 = 정량 효과 산정 가능, 안전 직결 |
| **실현가능성** | 확보 난이도 (역: 쉬울수록 고점) | 1~5 | 5 = 기존 자산으로 즉시 확보 / 1 = 신규 대량 생성 필요 |
| | 비용·기간 (역: 낮을수록 고점) | 1~5 | 5 = 추가 투입 거의 없음 |
| | 보안 제약 (역: 없을수록 고점) | 1~5 | 1 = 사외 반출 불가로 처리 방식 제약 |

`가치 점수 = (활용도 + 효과) / 2` · `실현가능성 점수 = (확보난이도 + 비용기간 + 보안제약) / 3`

## 3. 2×2 사분면 배치

```
 가치 高 │  ③ 전략 과제              ①  Quick Win
        │  (가치 高 / 실현 低)      (가치 高 / 실현 高)
        │  → 단계적 확보, 별도 투자   → 즉시 착수
        ├──────────────────────────────────────────
 가치 低 │  ④ 보류                   ② 여력 시 수행
        │  (가치 低 / 실현 低)      (가치 低 / 실현 高)
        │  → 이번 범위 제외          → 자동화 가능 시만
        └──────────────────────────────────────────
           실현가능성 低              실현가능성 高
```

| 사분면 | 해당 데이터 | 처리 방침 |
|---|---|---|
| ① Quick Win | | 1단계 즉시 착수 |
| ② 여력 시 | | 자동 확보 가능한 것만 |
| ③ 전략 과제 | | 2~3단계, 별도 투자 검토 |
| ④ 보류 | | 범위 제외 (사유 명시) |
